# Behold: Camelot

An Arthurian realm builder card game for KOReader

Copy this folder into `/koreader/plugins/`, restart KOReader, and select **Tools > Behold: Camelot**. It has a separate `beholdcamelot.lua` save file and starts a new game independently of other plugins.

Tap a card to focus it. **Inspect / flip** and **Rotate** only change the preview, never its game level. Hold offered cards to preview them during an action. Hold setup options for descriptions and rivals for strategies. **Realm / Rival** shows the live category-by-category score.

Inspired by Joe Klipfel's **Behold: Rome**. Please support Joe by [buying his game](https://www.thegamecrafter.com/games/behold%3A-rome-standard-edition-). This adaptation is not affiliated with or endorsed by the designer or publisher.
